Interactive Personal Blog Platform

Project Description:
This project is an interactive blog platform built with HTML, CSS, and JavaScript. Users can add, edit, and delete blog posts, with the changes being shown in a displayed list. All changes are saved through localStorage each time the page is refreshed.

Instructions:
Since data is stored in localStorage and there's no database or server in the back end, only index.html needs to be opened.

Development Process:
To begin, I created the HTML structure, then linked the DOM elements to the JavaScript. I then created an array to hold all of the blog posts as objects that can be identified through their IDs. I created event listeners for each of the buttons to be connected to add, edit, and delete functions. I also used a displayPost() function throughout the code so each change would be displayed. 

The biggest challenge was organizing the code and deciding what to add next after each element. To keep track of what changes were done, I tested the code incrementally through console.log. Each error was treated as a hint for what to do next. I also followed the instructions line by line to organize the code as accurately as possible.

Features Not Implemented:
With more time, more visual elements could've been added. There could also be more accessibility features as well. Since all blog posts are stored in localStorage, a database could've been created to incorporate a back-end component. Authentication could've been added on both the front and back end.
